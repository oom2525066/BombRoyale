# ボムロワイヤル (BombRoyale)

スマートフォン(Android)向けの、オンライン対戦3Dアクション(TPS視点)。
最大3人が街に集まり、武器や爆弾を拾って戦うバトルロイヤルです。最後まで生き残った1人が勝利します(制限時間5分。時間切れは生存者のうちキル数が最多の人の勝ち)。

## 特徴
- 爆弾やロケットが周囲の爆発物を巻き込んで連鎖する「誘爆」
- 爆風で崩れる街の建物
- 通常/高威力/火炎/凍結/炸裂のグレネード、ロケットランチャー、ショックウェーブガン、ブラスター

## 操作方法
| 操作 | タッチ | PC |
| --- | --- | --- |
| 移動 | 画面左の仮想スティック | WASD / 矢印キー |
| 視点 | 画面右をドラッグ | 右クリック押しながらマウス |
| 攻撃 | 右下の攻撃ボタン(グレネードは長押しで構え、離して投擲) | 画面上の攻撃ボタン |
| ジャンプ | ジャンプボタン | Space |
| 拾う | 「拾う」ボタン | E |
| 武器切替 | 下部のスロットをタップ | 1〜4キー |

## 遊び方
1. タイトル画面の「プレイ」で自動マッチング(ロビーコードでの参加も可能)
2. ホストが「ゲーム開始」を押すとカウントダウン後に試合開始
3. 街に出現する武器・爆弾を拾って敵を倒す
4. 最後の1人になれば勝利

## 開発環境
- Unity 6000.3.23f1(Universal Render Pipeline)
- Netcode for GameObjects / Unity Relay / Lobby
- `Assets` `Packages` `ProjectSettings` をそのままUnity Hubで開けます

## フォルダ構成
- `Assets/Scripts` ゲームのスクリプト(Combat / Core / Networking / Player / UI)
- `Assets/Scenes` ゲームシーン
- `Assets/Prefabs` プレイヤー・武器・爆弾のプレハブ
- `Assets/Resources` BGM・フォント・街(ボクセル)データ
- その他 `Assets` 配下は使用している外部アセット(使用分のみ)
